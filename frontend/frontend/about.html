SOBRE

GROOVE STORE

A Groove Store é um projeto académico de uma loja online de discos de vinil novos e usados.

OBJETIVO

O objetivo é desenvolver uma aplicação Full-Stack simples e compreender como a interface se liga ao servidor e à base de dados.

COMO FUNCIONA

Os visitantes podem consultar o catálogo, pesquisar discos, filtrar produtos e adicioná-los ao carrinho.

O catálogo está organizado em Rock, Pop, Jazz, Blues, Música Portuguesa e Soul / Funk / Disco.

TECNOLOGIAS

O frontend utiliza HTML, CSS e JavaScript. O backend utiliza Node.js e Express. A base de dados será desenvolvida em MySQL.

PROJETO ACADÉMICO

O carrinho é demonstrativo. Não existem pagamentos, cartões ou encomendas reais.
